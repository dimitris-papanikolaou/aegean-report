# Two Aegean Genomes

A single-page report of genomic ancestry findings for a Greek mother and son —
a full technical version and a plain-language companion, switchable in the
header.

The page is served for sharing by direct link and is kept out of search
results by the `noindex` / `nofollow` meta tags in `index.html`. The
`robots.txt` in this repo is **inert** — crawlers read robots.txt only at a
domain root, not at a project-site subpath — and is retained only as
documentation of intent. The meta tags do the work.

It contains no names, sample identifiers, or contact details, but it does
report genomic findings for two living people. Please treat accordingly and do
not redistribute.

`index.html` is self-contained apart from Google Fonts, and falls back to
Georgia / system sans if those do not load.
